# Changelog

## 1.0.0 (design-taste-brutalist)

Neo-brutalist fork of the taste-skill engine. Install name is `design-taste-brutalist`.

### Aesthetic (the point of this fork)

- **Section 4.0 Brutalist Aesthetic Override** - inverts the polished aesthetic rules (Sections 4, 7, 9) into a neo-brutalist rulebook: pure black/white required, flat fluorescent accents fully saturated, `border-radius: 0`, thick black borders, hard offset shadows, system and monospace display type, brutal contrast. Includes a "what still holds" clause (accessibility, em-dash ban, real images, performance gate) and a failure-mode guard ("looks accidentally broken" vs "intentional through consistency").

### Kept from the engine (unchanged)

Active Layout Casting (1.5), multi-variant mode (1.6), the real block library (12.0), the measured performance gate (15), the lean core + on-demand reference split, and `npm run check`. Only the aesthetic is inverted; the machinery is identical.
